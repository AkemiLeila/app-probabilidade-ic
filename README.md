# app-probabilidade-ic

Aplicativo didático desenvolvido para apoiar o ensino de Probabilidade e Estatística por meio de simulações, visualizações interativas e exploração de conceitos probabilísticos.

A ferramenta contempla diferentes recursos para o estudo de distribuições de probabilidade, comparações entre distribuições, simulações e experimentos clássicos, possibilitando relacionar conceitos teóricos com representações visuais e situações práticas.

O projeto foi desenvolvido no âmbito de uma pesquisa de Iniciação Científica, tendo como proposta a utilização de recursos computacionais como ferramenta de apoio à aprendizagem de conceitos de Probabilidade.
